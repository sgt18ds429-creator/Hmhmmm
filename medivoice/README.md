# ميدي فويز (MediVoice)

يحوّل تسجيل المحاضرة إلى ملزمة PDF مشروحة بالتفصيل، فيها المصطلحات الطبية وصور مطابقة للشرح.
الموقع منشور على Cloudflare Workers باسم `medivoice`.

## كيف يعمل

1. **الاستماع:** يقطّع التسجيل إلى مقاطع. Whisper (عبر Groq) يكتب مسودة، ثم Gemini يستمع للمقطع نفسه ويكتب التفريغ.
2. **الفهم والكتابة** (`writeNotes` في `public/app/pipeline.js`):
   - يقرأ النموذج المحاضرة كاملة، ويقسمها إلى أقسام حسب المواضيع.
   - يكتب كل قسم شرحاً مفصلاً بالفصحى، بعناوين ونقاط وجداول وملاحظات "مهم"، ويصحح أخطاء السمع في المصطلحات.
   - يفحص كل قسم: إذا خرج أقصر بكثير من كلام المحاضر، أو أسقط مصطلحاته، يعيد كتابته مرة مع تنبيه.
   - إذا تعذرت كتابة قسم يبقى نصه المفرّغ كاملاً، حتى لا تضيع أي معلومة.
   - في آخر الملزمة يضيف قائمة "أهم النقاط للمراجعة".
3. **الصور:** الكاتب يحدد مكان كل صورة وما يجب أن تُظهره بالضبط.
   - يبحث الموقع عن صور مرشحة في Wikimedia Commons و NIH Open-i.
   - Gemini ينظر إلى المرشحات نفسها ويختار الصورة المطابقة، ويكتب تعليقاً يصف ما فيها فعلاً.
   - إذا لم تطابق أي صورة، لا تُوضع صورة.
4. **القاموس و PDF:** قاموس المصطلحات، ثم PDF بصفحات A4 (يولّده Browser Rendering على الخادم).

عند رفع محاضرة جديدة، يختار المستخدم شكل الملزمة: شرح مفصّل (الافتراضي)، أو نص كامل بالفصحى، أو نص حرفي.
المحاضرات القديمة المحفوظة بنص مفرّغ يمكن تحويلها لشرح مفصل من صفحة الملزمة، بدون رفع التسجيل مرة ثانية.

## الملفات

| المسار | المحتوى |
|---|---|
| `public/` | الواجهة: `index.html` و `shell.js` (شاشة التفعيل) و `admin.*` (لوحة المدير) والأيقونات |
| `public/app/` | التطبيق: `pipeline.js` المسار الكامل، `prompts.js` تعليمات النماذج، `text.js` الترميز، `doc.js` عرض الملزمة، `pdf.js` و `paged.js` قالب PDF، `run.js` شاشات التحويل |
| `src/server.js` | العامل: الأكواد والأجهزة (Durable Object)، بروكسي Groq و Gemini، توليد PDF |
| `tools/build.mjs` | يجمع كل شيء في ملف واحد: `dist/worker.js` |
| `tools/deploy.mjs` | يرفع `dist/worker.js` للعامل الموجود ويبقي روابطه وأسراره كما هي |
| `tools/icons.cjs` | يولّد أيقونات PNG من `public/logo.svg` |
| `test/` | اختبارات بنماذج ومصادر وهمية (لا تحتاج مفاتيح ولا إنترنت) |

## التشغيل

```sh
npm test          # الاختبارات
npm run build     # dist/worker.js
CLOUDFLARE_API_TOKEN=... npm run deploy
```

التوكن يحتاج صلاحية **Workers Scripts: Edit** (قالب «Edit Cloudflare Workers» يكفي). في جلسات Claude السحابية يجب أن يكون
`api.cloudflare.com` مسموحاً في إعدادات الشبكة للبيئة؛ `NODE_USE_ENV_PROXY=1` في أمر النشر يمرّر الطلبات عبر بروكسي الجلسة.

النشر يستبدل الكود فقط، وتبقى هذه كما هي على Cloudflare:
- رابط `STORE` (Durable Object: `MediVoiceStore`)
- رابط `BROWSER`
- السران `KEYS_SECRET` و `ADMIN_PASSWORD`
